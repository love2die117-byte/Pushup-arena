# Push Up Arena: Knight's Quest S-RANK MASTERY

A web-based fitness gamification web application featuring real-time MediaPipe AI camera push-up form tracking, custom routines, hero analytics, and Firebase Google Authentication.

## Project Structure

```
.
├── index.html   # Main application structure & layout
├── style.css    # Complete app styling, dark theme, and mobile layout rules
├── auth.js      # Firebase SDK initialization & Google Sign-In handling
├── camera.js    # MediaPipe Pose detection engine & rep counting sensor
├── app.js       # Core game state management, UI switching, & profile calculations
└── README.md    # Documentation and setup instructions
```

## How to Run

1. Clone or download the project files to your computer or GitHub repository.
2. Open `index.html` directly in any web browser, or serve it using a local HTTP server (such as VS Code's **Live Server** extension).
